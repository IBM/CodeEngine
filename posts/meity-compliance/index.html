IBM Cloud Code Engine Is Now MeitY Compliant

Nov 19, 2026uwefassnacht

We are excited to announce that IBM Cloud Code Engine has achieved compliance with the standards set by the Ministry of Electronics and Information Technology (MeitY), Government of India. This milestone enables government agencies, public sector enterprises, and regulated organizations across India to deploy and scale containerized applications, batch jobs, and event-driven workloads on a fully managed serverless platform with full regulatory confidence.

What Is MeitY Compliance and Why Does It Matter?

The Ministry of Electronics and Information Technology (MeitY) establishes rigorous security, privacy, and operational standards for cloud service providers in India. MeitY empanelment and compliance are essential prerequisites for public sector departments, government entities, and highly regulated industries — such as Banking, Financial Services, and Insurance (BFSI) — looking to adopt cloud infrastructure and modernize applications.

With Code Engine achieving MeitY compliance, organizations in India can accelerate their digital transformation initiatives while meeting strict national standards for:

  • Data Sovereignty & Localization: Ensuring sensitive citizen, enterprise, and institutional data resides within compliant Indian data centers.
  • Enterprise-Grade Security: Meeting strict baseline controls for identity, access management, end-to-end data encryption, and network isolation.
  • Regulatory Governance: Adhering to government-mandated operational risk frameworks, continuous auditing, and resiliency requirements.

What Code Engine Delivers for Regulated Workloads

IBM Cloud Code Engine provides a unified serverless environment where developers and IT teams can deploy workloads without managing underlying Kubernetes clusters or virtual machine infrastructure.

By combining serverless agility with MeitY compliance, teams can run:

  • Scalable Web Applications & APIs: Host public-facing portals and private services that scale automatically with incoming traffic and scale to zero when idle — optimizing infrastructure costs while handling unpredictable traffic surges.
  • Batch Processing Jobs: Execute mission-critical data processing, report generation, analytics, and AI model inference runs at scale with dedicated compute resources.
  • Event-Driven Services: Trigger automated processing from object storage updates, Kafka streams, or database change notifications without standing up persistent listeners.
  • Private & Secure Networking: Deploy workloads with private-only endpoints that communicate securely over IBM Cloud’s private network backbone without internet exposure.

Deploying to the Chennai Region (in-che)

Code Engine is available in the Chennai Multi-Zone Region (in-che), designed with a 3-zone architecture providing fault-independent power, networking, and high availability.

Targeting the Chennai region with the IBM Cloud CLI is straightforward:

# 1. Log in to IBM Cloud
ibmcloud login --sso

# 2. Target the Chennai region
ibmcloud target -r in-che -g <your-resource-group>

# 3. Create a Code Engine project
ibmcloud ce project create --name meity-compliant-apps

# 4. Deploy your containerized application
ibmcloud ce app create --name gov-portal \
  --image icr.io/codeengine/hello \
  --min-scale 0 --max-scale 10
